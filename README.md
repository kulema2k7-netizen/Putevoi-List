# Путевые листы

Простое веб-приложение для учёта поездок и расхода топлива. Работает прямо в браузере телефона, не требует регистрации и установки из магазина.

**Открыть приложение:** https://kulema2k7-netizen.github.io/Putevoi-List/

## Возможности

- Запись за день: дата, начальный и конечный километраж, заправка, остаток топлива, часы ожидания, норма расхода.
- Автоматический расчёт пройденного пути, расхода по километражу и по времени, остатка топлива на конец дня.
- Начальный километраж и остаток подставляются из предыдущей записи.
- Журнал записей с удалением и пересчётом остатков.
- Итоги: количество дней, общий пробег и расход.
- Экспорт в JSON и CSV, загрузка из JSON.
- Установка на главный экран телефона и работа без интернета.

## Как установить на телефон

1. Откройте ссылку выше в Chrome.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

## Где хранятся данные

Все записи хранятся только в браузере на вашем устройстве (localStorage и IndexedDB). На сервер ничего не отправляется. Данные не переносятся между устройствами, поэтому периодически скачивайте резервную копию через кнопку «Скачать JSON».

## Состав проекта

- `index.html` — само приложение
- `manifest.webmanifest` — параметры установки
- `sw.js` — сервис-воркер для работы без сети
- `icon-192.png`, `icon-512.png` — иконки
